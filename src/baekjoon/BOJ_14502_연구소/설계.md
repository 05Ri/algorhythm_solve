# ☑️ 문제
⛓️‍💥 [14502 연구소](https://www.acmicpc.net/problem/14052)

## ⌨️ 입력
- 행, 열
    > lab[N][M]
- 연구소의 정보
    > 0: 빈칸 (3개 이상)   
    1: 벽   
    2: 바이러스 (2 ~ 10)

<br/>

## 🖥️ 출력
- 안전 영역의 최대 크기
    > maximumSafe

<br/>

## 💭 문제 조건 정의 & 해결

- 바이러스(2)는 상하좌우 인접한 빈 칸으로 퍼져나갈 수 있다.
    > BFS를 이용하여 퍼져나가기 시뮬레이션

<br/>

- 바이러스는 벽을 뚫지 못한다.
    > 벽(1)을 발견하면 BFS 리턴

<br/>

- 벽을 3개만 세운다.
    > 벽을 세울 위치 = lab[][]이 0인 곳   

- 벽을 세우는 방법
    > BFS로 모든 경우의 수를 따져본다. → 배열이 크다면 시간 초과 가능성 많음   

<br/>

- 벽을 세운 뒤 바이러스를 퍼트리고 BFS가 끝나면 lab 안에 공간(0) 세기 반복 → 가장 많은 공간을 가진 상황을 리턴

<br/>

## 🐞 디버깅

- 문제에서 행과 열이 3~8이라고 제시되어있었음. → 벽을 세울 위치를 모두 탐색해도 충분히 통과 가능.

<br/>

- 바이러스를 퍼트린 후 전으로 복구할 방법을 찾아야했다.
    > 바이러스를 퍼트리기 전 깊은 복사를 통해 lab을 복사해야한다.   
    아예 처음에 복사해두면 되지 않나? → 그러면 세운 벽이 없어지므로 바이러스를 퍼트리기 전에 복사해두는 것이 순서에 맞다.
