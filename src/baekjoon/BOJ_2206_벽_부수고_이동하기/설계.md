# ☑️ 문제
⛓️‍💥 [2206 벽 부수고 이동하기](https://www.acmicpc.net/problem/2206)

## ⌨️ 입력

- 가로 N, 세로 M
    > 1 ~ 1000

- 맵의 정보
    > map[N][M]   
    0은 빈 공간, 1은 벽

<br/>

## 🖥️ 출력
- 최단 거리
    > minDist = 최대값   
    길이 없으면 -1      
    ※ 시작점, 끝점 포함해서 센다.

<br/>

## 💭 문제 조건 정의 & 해결~~
- ~~DFS로 최단 거리를 찾으면 된다.~~ 
<U>**← 안되는 이유 디버깅으로 옮김**</U>

- BFS로 최단거리 찾기
    > 상하좌우로 한 칸씩 가능   
    요소는 \[i값, j값, 거리 값, 부술 수 있는지 여부\]로 넣기

<br/>

- 경로가 짧아진다면, 벽을 딱 한 개 부순다.
    > 이는 visited[][][]를 사용하여 파악.
    세번째가 벽을 부순 뒤인지의 여부

    > ~~벽들 중 하나를 없애고 DFS를 계속 돌린다?   
    용량 초과? → (8byte * 1000 * 1000 = 8MB)
    \+ (각종 변수와 배열 등...)   
    용량은 괜찮을 것 같으니 한 번 해보자.~~

<br/>

- 판단 기준
    > 빈 공간(map[][] == 0)일 때는 벽을 부셨는지 안부셨는지에 따라 방문체크를 하고 큐에 넣어준다.   
    벽(map[][] == 1)일 때는 visited[][][1]을 체크하고 벽을 부술 수 있는지 확인(isBreak == 0)하고 부술 수 있다면 부수고 큐에 넣어준다.

<br/>

## 🐞 디버깅
- 조건에 맞지 않으면 return 해버림
    > return을 해버리면 for문을 도는 도중 다른 경우를 전부 없애버리는 것이므로 건너뛰는 'continue' 사용이 적합.

<br/>

- 모든 경로를 찾는 경우에는 DFS가 적합하지만, **최단 경로**이므로 BFS가 적합
    > DFS로 탐색하는 경우 최악의 경우 O((N * M)<sup>2</sup>)가 되어 터짐.   
    따라서, <U>BFS + 상태 저장</U>으로 접근해야한다.

<br/>

- 벽을 부수는 판단 기준을 잘 잡을 것.
