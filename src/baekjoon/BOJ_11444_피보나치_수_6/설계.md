# ☑️ 문제
⛓️‍💥 [피보나치 수 6](https://www.acmicpc.net/problem/11444)

## ⌨️ 입력

- n번째
    > F<sub>n</sub>의 n (1 ~ 1,000,000,000,000,000,000(100경))

<br/>

## 🖥️ 출력
- n번째 피보나치 수를 1,000,000,007(10억 7)로 나눈 나머지
    > F<sub>n</sub> % 1000000007

<br/>

## 💭 문제 조건 정의 & 해결
- 피보나치 수 구하기
    > F<sub>0</sub> = 0   
     F<sub>1</sub> = 1   
     F<sub>n</sub> = F<sub>n-1</sub> + F<sub>n-2</sub>

<br/>

- 문제에서 정의하는 조건이 굉장히 큰 수이다.
    > int는 4 byte = 32 bit 사용   
    2<sup>32</sup> = 약 4.3억개의 숫자 표현 가능(-2.1억 ~ 2.1억) → "10억 7"로 나누기 가능  
    <br/>
    long 자료형 = 8byte = 64 bit   
    2<sup>64</sup> = 약 1800경 개의 숫자 표현 가능(-900경 ~ 900경) → 100경 번째의 피보나치 수 표현 불가능

<br/>

- "10억 7"로 나눈 나머지를 표현하면 되므로 작은 수로 공통점이 있는지 확인 → 5로 확인해보기

    | n | F<sub>n</sub> | F<sub>n</sub> % 5 |
    |---:|---:|---:|
    | 0 | 0 | 0 |
    | 1 | 1 | 1 |
    | 2 | 1 | 1 |
    | 3 | 2 | 2 |
    | 4 | 3 | 3 |
    | 5 | 5 | 0 |
    | 6 | 8 | 3 |
    | 7 | 13 | 3 |
    | 8 | 21 | 1 |
    | 9 | 34 | 4 |
    | 10 | 55 | 0 |
    ...   
    > 확인 가능한 것   
    F<sub>n</sub> % 5 = F<sub>n-1</sub> % 5 + F<sub>n-2</sub> % 5   
    이걸 적용하여 문제를 풀어보자   
    **→ 패턴 반복 문제 (피사노 주기) 시간초과로 불가능**

<br/>
