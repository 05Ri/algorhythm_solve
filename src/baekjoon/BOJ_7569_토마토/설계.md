# ☑️ 문제
⛓️‍💥 [7569 토마토](https://www.acmicpc.net/problem/7569)

## ⌨️ 입력

- 상자의 가로 M, 상자의 세로 N, 상자의 층 H
    > M (2 ~ 100) / N (2 ~ 100) / H (1 ~ 100)

<br/>

- 토마토의 상태
    > 1 : 익은 토마토   
    0 : 익지 않은 토마토   
    -1 : 빈 공간   
    storage[H][N][M]

<br/>

## 🖥️ 출력

- 토마토가 모두 익는 최소 일 수
    > 입력 받고 모두 익은 상태라면 0, 모두 익지 못하는 상태면 -1

<br/>

## 💭 문제 조건 정의 & 해결

- 3D BFS를 하면 될 것 같다.
    > 토마토가 익어나가는 방향을 판단하는 것이 중요할 것 같다.   
    상하좌우앞뒤   
    dm = { 0, 0, -1, 1, 0, 0 }   
    dn = { 0, 0, 0, 0, -1, 1 }   
    dh = { -1, 1, 0, 0, 0, 0 }   

<br/>

- 일 수를 알아야하기 때문에 큐에 넣을 정보에 추가한다.
    > int[] {m, n, h, days}

<br/>

## 🐞 디버깅

- 축이 하나 늘어난만큼 어디를 축으로 정할지, for문 순서를 잘 정해야함.
    > storage[높이][가로][세로]   
    storage[k][i][j]

<br/>


- 검사뿐만 아니라 토마토가 익었을 때 0 → 1을 해줘야 함.
