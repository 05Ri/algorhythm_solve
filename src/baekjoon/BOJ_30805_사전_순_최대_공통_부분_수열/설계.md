# ☑️ 문제
⛓️‍💥 [30805 사전 순 최대 공통 부분 수열](https://www.acmicpc.net/problem/30805)

## ⌨️ 입력

- 수열 $A$의 길이 N
    > N → 1 ~ 100

<br/>

- $A$의 요소들 N개
    > 1 ~ 100 사이의 수들

<br/>

- 수열 $B$의 길이 M
    > M → 1 ~ 100

<br/>

- $B$의 요소들 M개
    > 1 ~ 100 사이의 수들

<br/>

## 🖥️ 출력

- $A$와 $B$의 공통 부분 수열 중 사전 순으로 가장 나중인 수열의 크기 $K$
    > 

<br/>

- $K$ != 0 이라면 해당 수열 출력
    > 

<br/>

## 🐞 디버깅

- 그리디로 푸는 방법이었다.

    > 1. 우선 수열을 이루는 수가 100 이하인 자연수이므로 수열마다 100개의 리스트 공간을 부여하고 각 수열의 숫자들의 위치를 저장한다.
    > 1. 각 리스트를 검사할 때 이분탐색을 적용한다.
