# ☑️ 문제
⛓️‍💥 [17144 미세먼지 안녕!](https://www.acmicpc.net/problem/17144)

## ⌨️ 입력

- 집의 가로 R, 세로 C, 흐른 시간 T
    > R, C 범위: 6 ~ 50   
    T 범위: 1 ~ 1,000

<br/>

- 집의 정보
    - -1 : 공기청정기(위 아래로 붙어있음, 가장 윗 또는 아랫 행과 2칸 이상 떨어져 있음, 항상 1번 열에 설치되어 있음)   
        > 윗부분이 몇 번째 행에 있는지 저장해놓는다.   
        아랫부분 = 윗부분 + 1 
    - 0 ~ 1,000 : 미세먼지의 양.   
        > 정보를 받으면서 미세먼지 값(1 이상)이라면 큐에 바로 넣는다.

<br/>

## 🖥️ 출력

- T초가 지난 후 남아있는 미세먼지의 양
    > home[][]의 모든 숫자를 더하고 +2(공기청정기)   
    amountOfFineDust에 저장

<br/>

## 💭 문제 조건 정의 & 해결

- 먼지 확산
    - 1초 동안 상하좌우로 미세먼지가 있는 모든 칸에서 확산
        > BFS로 가능.    
        큐에 넣을 정보: [i, j, dustAmount]
    - 인접한 방향에 공기청정기 또는 범위 밖으로는 확산하지 않음
        > 다음 칸이 -1인지 밖인지 확인 후 확산
    - 확산되는 양은 1 / 5
        > (해당 칸의 미세먼지 양) + (dustAmount / 5) 후 큐에 넣음   
    - 확산된 양만큼 해당 칸의 미세먼지 양은 줄어든다.
        > (해당 칸의 dustAmount) - (퍼진 dustAmount들)을 계산하여 큐에 넣는다.

<br/>

- 공기 청정기쪽으로 미세먼지가 들어올 수 있도록 바람을 일으킨다.
    - 위쪽은 반시계방향, 아래쪽은 시계방향으로 순환한다.
        | 바람이 부는 위치 | 미세먼지 이동 방향 |
        |:---:|:---:|
        | 공기청정기 윗부분 행 <br/> 공기청정기 아랫부분 행 | 오른쪽 ➡️ |
        | 공기청정기 윗부분의 맨 끝 열 (house[][C - 1]) <br/> 공기청정기 아랫부분의 처음 열 (house[][0]) | 위쪽 ⬆️ |
        | 맨 윗 행 (house[0][]) <br/> 맨 아랫 행 (house[R - 1][]) | 왼쪽 ⬅️ |
        | 공기 청정기 윗 부분의 처음 열 (house[][0]) <br/> 공기청정기 아랫부분의 맨 끝 열 (house[][C - 1]) | 아래쪽 ⬇️ |
    - 미세먼지가 바람의 방향대로 모두 한 칸씩 이동한다.
        > 큐에 있는 요소들을 확인해서 바람 부는 범위에 맞게 i 또는 j 조정 후 다시 넣기
    - 공기 청정기로 들어간 미세먼지는 모두 정화된다.
        > 요소들 확인 시, 다음 칸이 공기청정기의 영역이면 다시 넣지 않아도 된다.

<br/>

## 🐞 디버깅

- 큐만 갱신하고 미세먼지 실제 공간(집)은 갱신하지 않음.
    > 시간이 달라져도 값이 그대로...

<br/>

- 기계를 가동하는 함수 구현은 잘 되어있으나 동시에 집의 값을 갱신하기에는 무리가 있음.
    > 새로운 배열을 만들어서 거기에 값을 집어넣자.

<br/>

- 인접한 먼지를 다루는 것이 어려움. (해당 좌표에 있는 큐 값을 꺼내서 먼지의 양을 갱신하기 어려움)
    > 새로운 배열을 만들어서 퍼진 먼지의 정도를 보고 합산.

<br/>

- 기계 가동하는 부분은 시간이 너무 오래 걸림. + 인덱스 꼬이기 쉬움.
    > 이동경로를 배열로 저장해서 순회하는 방식이 있다.
