# ☑️ 문제
⛓️‍💥 [15686 치킨 배달](https://www.acmicpc.net/problem/15686)

## ⌨️ 입력

- 도시의 크기 N / 살아남을 치킨 집의 개수 M
    > city[N][N]

<br/>

- 도시의 정보
    > ~~city[N][N]~~   
    0: 빈 칸   
    1: 집   
    2: 치킨 집

<br/>

## 🖥️ 출력
- 폐업시키지 않을 치킨집을 최대 M개를 골랐을 때, 도시의 치킨 거리의 최솟값을 출력
    > minChikenDistance

<br/>

## 💭 문제 조건 정의 & 해결

- 치킨집 M개를 골라서 집들과의 거리를 계산
    > 1. 치킨집 고르기 nCm   
    > 1. 고른 치킨집들에서 각각의 minChikenDistance 구하기

<br/>

- 순열 구하기
    > 집 리스트(homeList) 생성 및 집 넣기 /   
    치킨집 리스트(chickenPlaceList) 생성 및 치킨집 넣기,   
    리스트 크기로 방문배열(visited) 생성

<br/>

## 🐞 디버깅

- 거리가 제대로 나오지 않음
    > 출력하면서 살펴본 결과, 치킨거리를 구하는 함수에서 minDis를 제대로 갱신해주지 않음. → 논리를 제대로 정리하는 것이 중요...! 뭘 하고 있는지 주석을 달면서 작업하는 것도 좋겠다.

<br/>

- 컴파일에러 → 백준(Java11)에서 List.removeLast()라는 함수는 지원하지 않는다.
    > ctrl + 클릭하여 나오는 방법을 쓴다. → List.remove(this.size() - 1)

<br/>

- 시간초과: 치킨집을 고를 때 재귀를 치킨집들 리스트의 처음부터 시작하여 Combination이 아닌 Permitation의 방식이었음.
    > 재귀할 때 시작지점의 파라미터를 추가해줌.
