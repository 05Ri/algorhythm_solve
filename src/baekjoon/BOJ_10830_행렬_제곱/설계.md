# ☑️ 문제
⛓️‍💥 [행렬 제곱](https://www.acmicpc.net/problem/10830)

## ⌨️ 입력

- 행렬의 크기 N, 행렬의 B제곱
    > N(2 ~ 5) B(1 ~ 100,000,000,000)

<br/>

- 행렬 정보 / 각 원소는 0 ~ 1,000
    > N * N

<br/>

## 🖥️ 출력

- 행렬 A의 B제곱한 결과 % 1,000
    > N * N

<br/>

## 💭 문제 조건 정의 & 해결

- 행렬의 곱셈
    > [링크](https://mathbang.net/562)

<br/>

- 일반적인 방법으로 컴퓨터에게 B번 거듭제곱하라고 시키면 무조건 시간초과가 날 것이다.
    > 최적화 방법 생각해야함...

<br/>

## 🐞 디버깅

- 시간복잡도
    > 행렬 곱셈 O(N<sup>3</sup>). 거듭제곱은 O(log B) 단계 → 전체 O(N<sup>3</sup> · log B)   
    여기서 N <= 5, B <= 1 * 10<sup>11</sup> 이므로 충분히 빠르다고 한다.

<br/>

- 분할정복 사용
    > ⬇️ A<sup>B</sup> ⬇️   
    > - I (항등행렬) (B = 0)   
    > - (A<sup>B/2</sup>)<sup>2</sup> (B = 짝수)   
    > - A · (A<sup>B-1</sup>) (B = 홀수)

<br/>

- 이진수를 활용하여 곱셈 횟수를 줄이기
    > B & 1 → 지수가 홀수인지   
    B >>= 1 → 지수 2로 나누기 (이진수 옆으로 한 칸 옮기기)   

<br/>
