# ☑️ 문제
⛓️‍💥 [9996 한국이 그리울 땐 서버에 접속하지](https://www.acmicpc.net/problem/9996)

## ⌨️ 입력

- 파일 이름의 개수
    > int N

<br/>

- 파일 이름의 패턴
    > String[] pattern

<br/>

- 파일 이름들
    > String fileName

<br/>

## 🖥️ 출력

- 파일 이름과 패턴이 일치하는지 여부
    > 일치하면 "DA", 아니면 "NE"

<br/>

## 💭 문제 조건 정의 & 해결

- 조건들
    > 파일 이름은 소문자로만 이루어짐   
    패턴의 맨 앞과 뒤에는 "*"이 없음   
    **"*"은 딱 하나임**

<br/>

- String.split("*")을 이용하여 패턴의 배열을 만든다.
    > 각 요소마다 일치하는지 확인하기 위함

<br/>

- ~~파일이름과 패턴의 각 요소가 일치하는지 확인~~
    > ~~패턴의 요소 안에 문자열의 문자들과 파일이름의 요소가 일치하는지 확인~~

<br/>

- 앞과 뒤가 pattern과 일치하는지 검사
    > pattern[0]은 앞에서부터, pattern[1]은 맨 끝에서부터 일치해하는지 검사한다.

<br/>

## 🐞 디버깅

- 문제를 잘 읽자.
    > 원래 생각한대로 "*"이 여러개 들어갈 수 있다면 정규식 문제로, 난이도가 대폭 상승한다...

<br/>

- Exception in thread "main" java.util.regex. PatternSyntaxException: Dangling meta character '*' near index 0
    > "\*"를 단독으로 쓰면 정규식 표현이기 때문에 오류가 저렇게 난다. 따라서 "\\\\*" 이렇게 'escape'를 해주어야 실제 문자로 인식하고 메소드가 제대로 동작한다. 다른 정규식 표현으로는 [., +, ?]가 있으니 주의하자.

<br/>

- 1   
ab*ba   
aba
    > 이런 테스트 케이스가 있다면 맞다는 것을 출력하게 된다. 이를 방지하기 위해 패턴의 길이와 파일 이름의 길이보다 크다면 바로 틀리다는 것으로 출력해준다.

<br/>
