# ☑️ 문제
⛓️‍💥 [16236 아기상어](https://www.acmicpc.net/problem/16236)

## ⌨️ 입력

- 공간의 크기 N (2 ~ 20)   
    - 0 : 빈 공간
    - 1 ~ 6 : 먹을 물고기의 크기
    - 9 : 아기 상어
    > board[][]   
    공간 정보를 입력 받을 시, 아기 상어의 위치(loc[])를 기억하고 빈 공간으로 채워넣는다.

## 🖥️ 출력
- 먹을 수 있는 물고기를 다 먹고 난 뒤의 시간
    > time

## 💭 문제 조건 정의 & 해결
- 처음에 아기 상어의 크기 = 2
    > babySharkGrowth

<br/>

- 아기 상어는 1초에 상하좌우로 한 칸씩 이동 가능
    > BFS로 탐색 → 큐 사용 queue, 탐색 깊이마다  depth++

<br/>

- 물고기와 아기 상어 크기 조건
    - 아기 상어 크기 < 물고기 크기 → 이동 불가, 잡아먹기 불가
        > babySharkGrowth < board[][]   
        queue에 넣지 않음
    - 아기 상어 크기 = 물고기 크기 → 이동 가능, 잡아먹기 불가
        > babySharkGrowth == board[][]   
        queue 넣기 가능
    - 아기 상어 크기 > 물고기 크기 → 이동 가능, 잡아먹기 가능
        > babySharkGrowth > board[][]   
        queue 넣기 가능, fishCnt++

<br/>

- 아기 상어의 성장 조건
    - 자신의 크기와 같은 수의 물고기를 먹어야 +1
        > fishCnt == babySharkGrowth   
        babySharkGrowth++

<br/>

- 같은 거리에 잡아 먹을 수 있는 물고기가 여러마리면 맨 위가 우선, 그 다음 왼쪽 우선
    > BFS 탐색 순서 → 상, 좌, 우, 하

<br/>

- 가장 가까운 물고기 탐지 및 상어 이동
    > board[][] > 0인 값이 탐지된다면 우선순위가 높은 물고기이므로 depth만큼 time에 더해주고, board[][] = 0이 된다. loc[]도 업데이트 해준다.
    
<br/>

## 🐞 디버깅
- 논리오류: 행과 열, x와 y는 우선하는 축이 다르다.
    > board[행][열] <=> board[y][x]

<br/>

- 논리오류: BFS를 상, 좌, 우, 하 순서로 탐색하다가 먹을 수 있는 물고기가 탐지 된다면 바로 리턴함.
    > **※ 주의 ※**   
    BFS는 탐지 순서에 의해 우선순위가 보장되지 않음
    
<br/>

- 복기 해야할 점: BFS의 레벨 단위 탐색 구조
    > 탐색 전, 큐의 사이즈를 기준으로 삼으면 동등한 레벨을 탐색할 수 있음.
